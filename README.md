# TAT Monitor — Ground Operations Calculator

Aplicación web para control y monitoreo en tiempo real de tiempos de rampa (**Turn Around Time - TAT**) en operaciones aeroportuarias.

## 🚀 Características
- **Control de Hitos de Turn Around:** Tiempos estandarizados por aerolínea (SKY, LATAM).
- **Contador en Tiempo Real:** Monitor continuo hacia la entrega del vuelo con alertas visuales.
- **Checklist Operativo:** Verificación de pasos clave antes del pushback.
- **Reportes y WhatsApp:** Resumen rápido para compartir novedades de rampa por WhatsApp o exportar reporte de turno.
- **Diseño Móvil y Rápido:** Optimizado para tablets y smartphones en rampa.

## 🛠️ Instalación y Uso Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```
